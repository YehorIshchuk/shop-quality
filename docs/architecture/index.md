# Рівень 4 · Architecture Docs

> **Питання рівня:** чому система влаштована саме так?

Архітектурний паспорт з ЛР10, мігрований у базу знань:

| Документ | Що в ньому | Для кого |
|---|---|---|
| [[sdd]] — System Design Document | **як влаштована всередині**: C4-контекст і контейнери, компоненти, модель даних, контракти | розробники, QA |
| [[isd]] — Infrastructure Specification | **де і на чому працює**: середовища, змінні, порядок запуску, конвеєр, RTO/RPO | DevOps |
| [Кущ ADR](adr/index.md) | **чому саме так**: рішення з альтернативами, статуси, незмінюваність | архітектор, розробники |
| [[blueprint-lab8]] | історична схема рефакторингу ЛР8 | **deprecated** → SDD |

Порядок читання: SDD §2–3 (C4) → ADR-0001 → SDD §4–6 → ISD §1–3.
