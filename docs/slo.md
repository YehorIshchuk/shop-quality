# Контракт рівня послуг: SLI → SLO → SLA

| Термін | Що це | У Shop Quality |
|---|---|---|
| **SLI** — Service Level Indicator | **виміряний показник**: частка «добрих» подій серед усіх валідних | наприклад, частка відповідей `/api/*` не 5xx |
| **SLO** — Service Level Objective | **внутрішня ціль** команди для SLI за вікно | ≥ 99.5 % за 30 днів |
| **SLA** — Service Level Agreement | **зовнішня обіцянка** клієнту, консервативніша за SLO | ≥ 99.0 % за 30 днів |

Різниця **SLA − SLO = буфер надійності**: команда реагує, щойно порушено SLO, — задовго до того, як порушиться
зобов'язання перед клієнтом. **Error Budget = (100 % − SLO) × вікно** — скільки «поганих» хвилин можна витратити
на зміни й експерименти, не порушивши ціль.

## Бюджети помилок (вікно 30 днів = 43 200 хв)

Розраховано і перевірено `python3 tools/slo_budget.py --check` (крок конвеєра `docs.yml`):

| SLI | SLO | SLA | Бюджет SLO, хв/міс | Бюджет SLA, хв/міс | Буфер, хв | Виміряно 2026-11-22 |
|---|---|---|---|---|---|---|
| `api-availability` | 99.5 % | 99.0 % | (100 − 99.5) % × 43 200 = **216** | **432** | 216 | 100 % (6000 запитів, 0 × 5xx) |
| `api-latency` | 99.0 % | 97.0 % | (100 − 99.0) % × 43 200 = **432** | **1 296** | 864 | 100 % вікон, p95 = 9.2 мс |
| `pipeline-verdict` | 95.0 % | 90.0 % | (100 − 95.0) % × 43 200 = **2 160** | **4 320** | 2 160 | 100 % (5 запусків, 0 збоїв інструментів) |

Значення «виміряно» — синтетична проба `tools/sli_probe.py` на живому API (короткий сеанс) та історія GitHub Actions;
постійного Prometheus/Grafana у проєкті немає, тому місячні значення будуть накопичуватися пробами за регламентом
[плану супроводу](maintenance-plan.md).

## Політика витрачання бюджету

| Витрачено бюджету SLO | Режим |
|---|---|
| < 50 % | **Нормальний** — релізи за звичайним RFC-процесом |
| 50–100 % | **Обережний** — кожен нормальний RFC: перевірений план відкату (RB-001 §7) і явний голос SRE на CCB |
| ≥ 100 % | **CHANGE FREEZE** — функціональні релізи заморожено; CCB погоджує лише «термінові» зміни, що підвищують стабільність (виправлення, CAPA). Freeze знімається, коли бюджет знову > 0 або CCB підтвердила ефективність CAPA |

Політика узгоджена з регламентом [Change Control Board](changes/CCB-001.md): звіт про витрату бюджету — на кожному засіданні.
